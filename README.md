Online Book Store

Introduction

The Online Book Store is a web-based e-commerce application developed using Python and Django. It allows users to explore books, view book details, and purchase books online through a user-friendly interface.

The main objective of this project is to make buying books easier and more convenient by providing an online platform for book lovers.

Key Features

- Browse and explore books.
- View book details and information.
- User-friendly interface.
- Online book purchasing functionality.
- Secure payment integration using Stripe.
- Admin panel for managing books and website data.

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Django
- Database: SQLite
- Payment Gateway: Stripe
- Version Control: Git and GitHub

Project Objective

To develop an easy-to-use online platform where users can discover and purchase books conveniently from anywhere.
